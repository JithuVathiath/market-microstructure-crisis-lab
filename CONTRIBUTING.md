# Contributing

Thank you for improving the Market Microstructure Crisis Lab.

1. Open an issue describing the research or engineering change.
2. Keep mechanisms transparent and deterministic under a fixed seed.
3. Add or update tests for behavioral changes.
4. Run `pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`, and `pnpm e2e`.
5. Explain modeling assumptions and limitations in the pull request.

New agent rules should document their information set, decision cadence, constraints, and intended teaching value. Do not add live brokerage connections or represent synthetic output as investment guidance.
